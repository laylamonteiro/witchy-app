⚡ SETUP RÁPIDO (5 MINUTOS)
═══════════════════════════════════════════════════════════════════════════

1️⃣ COPIAR ARQUIVOS
──────────────────

No seu projeto witchy-app, copie os arquivos desta forma:

witchy-app/
├── .github/                    ← CRIAR ESTES DIRETÓRIOS
│   └── workflows/
│       ├── auto-increment.yml  ← COPIAR ESTES 4 ARQUIVOS
│       ├── ci.yml
│       ├── release.yml
│       └── README.md
└── scripts/                    ← CRIAR ESTE DIRETÓRIO
    └── bump_version.sh         ← COPIAR ESTE ARQUIVO

2️⃣ DAR PERMISSÃO AO SCRIPT
───────────────────────────

cd witchy-app
chmod +x scripts/bump_version.sh

3️⃣ CONFIGURAR GITHUB
─────────────────────

a) Acesse: https://github.com/laylamonteiro/witchy-app/settings/actions

b) Em "Workflow permissions":
   ✅ Marque: "Read and write permissions"
   ✅ Marque: "Allow GitHub Actions to create and approve pull requests"
   
c) Clique em "Save"

4️⃣ FAZER COMMIT E PUSH
───────────────────────

git add .github/ scripts/
git commit -m "🚀 Adiciona CI/CD workflows"
git push origin main

5️⃣ TESTAR
─────────

a) Acesse: https://github.com/laylamonteiro/witchy-app/actions

b) Você deve ver os workflows listados:
   - 🔄 Auto Increment Version
   - 🚀 Build & Release Android
   - 🧪 CI - Pull Request

c) Clique em "Build & Release Android" > "Run workflow"
   - Branch: main
   - Increment type: build
   - Clique em "Run workflow"

d) Aguarde ~5 minutos e veja a mágica acontecer! ✨

💡 COMANDOS ÚTEIS
═══════════════════════════════════════════════════════════════════════════

# Incrementar versão localmente (interativo)
./scripts/bump_version.sh

# Ver workflows rodando
gh run list

# Ver logs de um workflow
gh run view [run-id] --log

# Disparar workflow manualmente
gh workflow run release.yml

# Criar release via tag
git tag v1.1.0
git push origin v1.1.0
