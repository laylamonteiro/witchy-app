🚀 PRÓXIMOS PASSOS (5 MINUTOS)
═══════════════════════════════════════════════════════════════════════════

1️⃣ COPIAR ARQUIVOS PARA SEU PROJETO

cd ~/seu-caminho/witchy-app

# Copiar workflows
cp -r github-actions-setup/.github .

# Copiar scripts
cp -r github-actions-setup/scripts .
chmod +x scripts/bump_version.sh

2️⃣ CONFIGURAR PERMISSÕES NO GITHUB

Acesse: https://github.com/laylamonteiro/witchy-app/settings/actions

Marque:
  ✅ Read and write permissions
  ✅ Allow GitHub Actions to create and approve pull requests

Clique em "Save"

3️⃣ FAZER COMMIT E PUSH

git add .github/ scripts/
git commit -m "🚀 Adiciona CI/CD com builds paralelos"
git push origin main

4️⃣ TESTAR!

Acesse: https://github.com/laylamonteiro/witchy-app/actions
Clique em: "Build & Release Android" → "Run workflow"
Selecione: Branch main, Increment type: build
Aguarde ~14 minutos
Baixe APK e/ou AAB dos artifacts

═══════════════════════════════════════════════════════════════════════════
📊 JOBS E SUAS FUNÇÕES
═══════════════════════════════════════════════════════════════════════════

Job 1: 🔧 Prepare & Version (1 min)
  → Incrementa versão, commita, define outputs

Job 2: ✅ Validate Code (2-3 min)
  → Roda analyze e testes

┌─────────────────────────── PARALELO ⚡ ───────────────────────────┐

Job 3: 📱 Build APK (5-7 min)          Job 4: 📦 Build AAB (5-7 min)
  → flutter build apk                     → flutter build appbundle
  → Upload APK artifact                   → Upload AAB artifact

└──────────────────────────────────────────────────────────────────┘

Job 5: 🎉 Create Release (1 min)
  → Baixa APK + AAB, cria GitHub Release

Job 6: 🎮 Upload to Play Store (1-2 min, opcional)
  → Upload do AAB para Play Store

Job 7: 📊 Build Summary (<1 min)
  → Resumo final com status de tudo

💡 DICAS DE USO
═══════════════════════════════════════════════════════════════════════════

🔹 Desenvolvimento diário:
   • Push para main → versão incrementa automaticamente
   • Abre PR → CI valida seu código
   • Merge → build number vai de +5 para +6

🔹 Fazer release:
   • GitHub UI: Actions → Run workflow → Seleciona tipo
   • Ou: git tag v1.1.0 && git push origin v1.1.0
   • Aguarda ~14 min → Baixa APK/AAB

🔹 Usar APK gerado:
   • Ótimo para: testes internos, distribuição direta, debug
   • Instala diretamente no Android
   • Não precisa da Play Store

🔹 Usar AAB gerado:
   • Necessário para: publicar na Play Store
   • Upload na Play Console
   • Google gera APKs otimizados automaticamente

🆘 SE ALGO DER ERRADO
═══════════════════════════════════════════════════════════════════════════

1. Verifique permissões do GitHub Actions (passo 2 acima)
2. Veja os logs do job que falhou no GitHub UI
3. Consulte seção "Troubleshooting" no GITHUB_ACTIONS_SETUP.txt
4. Workflows têm comentários explicando cada passo

Erros comuns:
  ❌ Permissões não configuradas → Vá em Settings → Actions
  ❌ pubspec.yaml inválido → Rode flutter pub get localmente
  ❌ flutter analyze falha → Corrija warnings primeiro
