# Baralho Rider-Waite (imagens)

Coloque aqui as 78 imagens do deck Rider-Waite-Smith (domínio público —
uma fonte confiável é a categoria "RWS Tarot" do Wikimedia Commons).

**Formato**: `.webp` (preferido) ou troque a extensão em
`tarot_card_model.dart -> assetPath`. Largura recomendada: ~350 px.

**Nomes exatos dos arquivos:**

- Arcanos Maiores: `major_00.webp` (O Louco) até `major_21.webp` (O Mundo)
- Paus: `wands_01.webp` … `wands_14.webp`
- Copas: `cups_01.webp` … `cups_14.webp`
- Espadas: `swords_01.webp` … `swords_14.webp`
- Ouros: `pentacles_01.webp` … `pentacles_14.webp`

Nas cortes: `11` = Valete (Page), `12` = Cavaleiro (Knight),
`13` = Rainha (Queen), `14` = Rei (King).

Enquanto um arquivo não existir, o app mostra um placeholder estilizado
com o nome da carta — nada quebra.

Para o baralho de Marselha (futuro): mesma convenção em
`assets/tarot/marseille/`.
