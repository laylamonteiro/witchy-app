# Baralho Rider-Waite (imagens)

Deck "sm_RWSa" (domínio público). Nomenclatura usada pelo app
(`tarot_card_model.dart -> assetPath`):

- `sm_RWSa-T-00.webp` … `sm_RWSa-T-21.webp` — Arcanos Maiores
- `sm_RWSa-W-*` Paus · `sm_RWSa-C-*` Copas · `sm_RWSa-S-*` Espadas ·
  `sm_RWSa-P-*` Ouros
- Números dos menores: `0A` = Ás, `02`…`10`, `J1` = Valete,
  `J2` = Cavaleiro, `QU` = Rainha, `KI` = Rei
- `sm_RWSa-X-BA.webp` — verso da carta (usado no embaralhamento)

Para Marselha (futuro): mesma convenção em `assets/tarot/marseille/`.
